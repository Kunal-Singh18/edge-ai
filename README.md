# **Motor Fault Detection using Edge AI**  

[![GitHub](https://img.shields.io/badge/GitHub-Repository-blue)](https://github.com/Kunal-Singh18/edge-ai)  

## **Overview**  
This project leverages **Edge AI** to detect motor faults based on **vibration patterns**, using data from an accelerometer sensor. A **deep learning model** runs on an **STM32F4** microcontroller to analyze real-time sensor data and identify potential faults efficiently.  

## **Key Features**  
- **Sensor Data Acquisition:** Capturing real-time vibration data from the ADXL345 accelerometer via I2C.  
- **Edge AI Inference:** Running a trained deep learning model on the STM32F4 for fault detection.  
- **Data Preprocessing:** Filtering and normalizing accelerometer signals.  
- **Real-Time Analysis:** Ensuring minimal latency with optimized embedded code.
